## 제품 정체성

**"투자 초보가 자신의 탐색 성향에 맞는 관점부터 시작해, 공개 지표로 기업을 좁혀 보고 알아보는 앱"**

핵심 원칙: **"사람-종목 매칭 금지, 사람-관점 연결 허용"**

```text
허용:  사용자 탐색 성향  →  관점 설명  →  조건 직접 선택  →  공개 지표 결과
금지:  사용자 투자 성향  →  자동 조건 적용  →  종목 매칭  →  "당신에게 맞는 기업"
```

## 사용자가 얻는 변화

| 전 | 후 |
|---|---|
| 기업명은 알지만 무엇을 봐야 할지 모른다 | 탐색 관점에 따라 확인할 공개 지표 하나를 이해한다 |
| 숫자와 공시가 모두 투자 판단처럼 느껴진다 | 공개 지표·출처·기준일을 분리해서 확인한다 |
| 바로 판단해야 할 것처럼 느낀다 | 다시 볼 기업으로 남긴다 |

성공한 첫 경험 = **사용자가 자기 말로 설명할 수 있게 되는 것** (사야겠다는 느낌 아님)

## 법무 가드

**핵심 질문**: "이 제품이 성향을 바탕으로 특정 종목 투자 판단을 제공하는가?" → **아니다**

**출시 차단 사유** (§15.2 발췌)
- 탐색 성향 선택 후 조건 자동 선택·적용
- "당신에게 맞는 기업"·"성향에 맞는 종목"·"추천 종목" 표현
- 서버에 사용자별 탐색 성향·조건·종목 관심 프로필 저장

**표현 가드** (§18)
- 금지: "추천 종목" / "맞춤" / "성향 적합도" / "안전한 기업" / "좋은 기업"
- 허용: "탐색 관점" / "현재 켠 조건에 해당하는 기업" / "공개 지표 보기"

## 로드맵

**Gate 0 → Phase 1-A 내부 베타 → Gate 1 → Phase 1-B 외부 MVP → Gate 2 → 1-C 후보 실험**

**용어 구분**
- **Phase**: 사용자 경험 범위 변화
- **Gate**: 다음 단계 진입 판단 지점
- **Iteration**: 동일 범위 안에서 지표 개선 반복
- **Candidate Experiment**: Gate 통과 후 확장 후보 실험

Phase 1-B 외부 출시 범위: 2탭(발견·관찰), 조건 3개 + 상태 정보 1개, 탐색 관점 3종, 코스피·코스닥 − 거래정지·관리·상폐사유
