# StockLoop 프로토타입 UI 스펙 (사장님 시연용)

> **이 문서의 목적**: Claude design(`mcp__visualize__show_widget`)으로 **인터랙티브 모바일 앱 프로토타입**을 만들기 위한 빌드 지시서.
> **고지**: 본 프로토타입은 **전부 목업(예시 데이터)**이며 실제 백엔드·실시세·투자자문이 아니다. 모든 화면에 "프로토타입 · 예시 데이터" 워터마크를 상시 노출한다.
> **근거 문서**: [prd.md](prd.md), [issues/](issues/), `project_wise` 프로토타입(지혜로운 투자 앱).

---

## 1. 시연 목표 & 대상

- **대상**: 사장님(투자자·멘토)
- **목표**: 인프라가 아니라 **"추천 → 검증 → 진화" 폐루프**와 **"상승 본질 5단계"** 라는 투자 논거를 화면으로 체감시킨다.
- **한 줄 메시지**: "찾고 → 설명하고 → 검증하고 → 진화한다."

---

## 2. 산출 형태 (Blocker 픽스 반영)

- **두 가지를 동시에 산출한다.**
  1. `show_widget`(HTML 모드)로 채팅 인라인 미리보기.
  2. **동일 마크업을 `project_stockloop/prototype/stockloop_demo.html` 자기완결 standalone 파일로 저장** — 외부 의존·인라인 자산 없이 폰 브라우저로 열거나 노트북에서 풀스크린 시연 가능. (내일 실제 시연 전달 경로 확보)
- **폼팩터**: 모바일 앱 목업. 휴대폰 프레임(폭 ~390px, 라운드 베젤) 중앙 배치.
- **단일 HTML 하나**에 5개 화면을 모두 넣고 내부 JS로 전환(시연 시 아티팩트 하나만).
- **언어**: 한국어.
- **show_widget 제약 준수**: `read_me` 선행, 배경 투명, CSS 변수 사용, 스크립트는 스트리밍 후 1회 실행 → 모든 JS를 단일 `init()` + 이벤트 위임으로 작성(Advisory 픽스).
- standalone 파일은 show_widget 제약과 무관하게 자체 `<style>`·폰트·폰 프레임을 포함해 독립 동작.

## 3. 비주얼 토큰

깔끔한 라이트 핀테크 룩(토스·삼성증권풍). 플랫, 그라데이션·그림자 남용 금지.

| 토큰 | 값 |
|---|---|
| 베이스 배경 | `#F7F8FA` |
| 서피스(카드) | `#FFFFFF` |
| 기본 텍스트 | `#1A1D29` |
| 보조 텍스트 | `#6B7280` |
| 브랜드 액센트 | `#2563EB` (딥블루) |
| 리스크 High | `#EF4444` |

- standalone 파일에서는 위 hex를 직접 사용. show_widget 인라인 버전에서는 가능한 한 CSS 변수로 매핑.

## 4. 전역 구조

- **휴대폰 프레임** 안에 화면 영역 + **하단 탭 바**(홈 / 추천 / 검증 / 진화).
- **상시 워터마크**: 프레임 상단 또는 모서리에 "프로토타입 · 예시 데이터" 작은 배지(Advisory 픽스).
- **범위 라벨**(Advisory 픽스): 홈 상단에 한 줄 — "최종 소비자 앱 비전 (v1은 운영자용 엔진)". 사장님이 v1 범위를 오해하지 않게.
- 종목 카드 탭 → **종목 상세** 슬라이드 인(오버레이/풀스크린). `position: fixed` 금지 — 정상 플로우 오버레이로 구현.

## 5. 화면별 스펙

### 화면 1 — 홈 대시보드
- **헤더**: 브랜드 `StockLoop` + 한 줄 정의("상승의 본질을 분석하고 검증하는 투자 엔진").
- **범위 라벨** + **워터마크 배지**.
- **핵심 배너**: "우리 엔진은 **수급·기대·근거·구조·지속성**을 본다" (상승 본질 5단계).
- **6 KPI 카드**(2×3 그리드): 오늘 감지 후보 · 신규 가상매수 · 평균 점수 · 오늘 공시 · 실패 경고 · 최근 7일 성공률.
- **큰 CTA 버튼**: `[오늘의 분석 실행]`.

### 화면 2 — 추천 종목 (급등주 스캐너)
- 종목 카드 리스트. 카드당:
  - 종목명 + 종목코드
  - **총점**(원형 게이지, 0~100)
  - 핵심 시그널 2~3개(칩): 예 "거래량 급증", "수주 공시", "외인 순매수"
  - **리스크 배지**(High/Med/Low, 색상 코딩)
- 카드 탭 → 화면 3.

### 화면 3 — 종목 상세 (오버레이)
- **① 상승 본질 5단계**: 수급·기대·근거·구조·지속성 각 단계 충족도 표시(체크/막대).
- **② 5축 점수 막대**: 가격 모멘텀 · 거래량 검증 · 뉴스 연관성 · 뉴스 감성 · 추가 상승 여력.
- **③ AI 추천 사유**: 2~3문장 자연어 문단(목업).
- **④ 리스크 등급** + 한 줄 근거.
- **⑤ `[가상매수]` 버튼**.

### 화면 4 — 검증 & 성과 (차별점)
- **가상매수 포트폴리오** 리스트.
- **기간별 수익률**: 7일 / 30일 / 90일 (각 항목 "예시" 태그 — Advisory 픽스).
- **성공률 게이지** + 성공/실패 판정 배지(±5% 기준).
- **실패 사례 1건 + 실패 태그**(예: "고점 추격", "뉴스 과열") — "검증하고 반성한다"를 시각화.

### 화면 5 — 진화 (엔진 버전)
- **버전별 성공률 라인**(v1.0 → v1.1) + 가중치 변화 요약.
- **캡션**(Advisory 픽스): "향후 이렇게 진화한다 — 예시 시뮬레이션". (과약속 인상 차단)

## 6. 인터랙션

- 하단 탭: 홈/추천/검증/진화 전환.
- 종목 카드 탭 → 상세 슬라이드 인, 닫기 버튼으로 복귀.
- **핵심 데모 모먼트**: 홈 `[분석 실행]` → 진행 바 0→100% 애니메이션(스캔 연출) → 자동으로 "추천" 탭 이동.
- 리스크 색상 코딩 일관 적용.
- 모든 JS는 단일 `init()`에서 이벤트 위임으로 바인딩(스트리밍 후 1회 실행 안정성).
- 표시되는 모든 숫자는 `Math.round`/`toFixed`로 반올림.

> 실종목명을 쓰되 수익률·성공률 등 성과 수치에는 "예시" 태그를 달고, 비현실적 고수익은 피한다(Advisory 픽스).

| 에코프로 | 086520 | 74 | 2차전지 반등·뉴스 빈도↑ | High |
| 삼성전자 | 005930 | 68 | 외인 매수 전환·반도체 업황 | Low |

## 8. 시연 시나리오 (60~90초, md 고정 동선)

1. **홈** KPI 6장 훑기 + 핵심 배너로 "본질 5단계" 한마디.
2. `[분석 실행]` 눌러 스캔 연출(0→100%) → 추천 탭 자동 이동.
3. **추천** 1위(한미반도체) 탭 → **상세**.
4. **상세**에서 본질 5단계 + 5축 점수 + AI 사유 + 리스크 설명 → `[가상매수]`.
5. **검증** 탭: 성공률·성공/실패 배지·실패 태그 → "맞았는지 끝까지 추적한다" 강조.
6. **진화** 탭: 버전별 성공률 상승 → "학습한다"로 루프 닫기.
