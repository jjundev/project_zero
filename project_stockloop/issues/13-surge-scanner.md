## What to build
대시보드의 급등주 스캐너 모듈. v1은 **전일 일봉 기반 모멘텀 스캐너**로 한정한다(실시간 틱/분봉은 Phase 2). 한 줄에 종목명·총점·핵심 시그널 2~3개·리스크 등급·가상매수 버튼·상세 분석 버튼을 노출하는 실용 테이블.

## Acceptance criteria
- [ ] 전일 일봉 기반으로 모멘텀 상위 종목을 선별한다
- [ ] 테이블이 종목명·총점·핵심 시그널 2~3개·리스크 등급을 한 줄에 표시한다
- [ ] 가상매수 버튼·상세 분석 버튼이 동작한다
- [ ] v1 한정(전일 일봉) 범위가 UI/문서에 명시된다
- [ ] 테이블 렌더 컴포넌트 테스트가 통과한다
