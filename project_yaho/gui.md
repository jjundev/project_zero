## 0. 표시 원칙 (Display Principles) — 흔들리지 않는 골격

대상은 **뉴스·유튜브에 휘둘리는 초보~초중급 개인투자자**. 핵심 철학은 "정답 찍기가 아니라 생각 돕는 나침반". 모든 화면은 아래 3단 위계 — **기본은 단순하게, 깊이는 펼쳐서.**

| 위계 | 노출 시점 | 요소 |
|---|---|---|
| **1차 (상시)** | 항상 | 오늘 한 줄 요약 · 이야기 카드(이름+색+**단계 라벨**+화살표) · 면책 배너 · 갱신 시각 |
| **2차 (탭 진입 시)** | 이야기 상세·종목 결과에서 | 2~3줄 설명 · 대표/추종 종목 · 과거 패턴 한 줄 · **숫자(%)·그래프** |
| **3차 (요청 시 숨김)** | 클릭해야 | 갱신 방법·데이터 출처 · 단계 판정 근거 설명 · 범례 상세 |

- **P1 색은 단독으로 의미를 전달하지 않는다** — 단계는 항상 **[색 + 단계 라벨 텍스트 + 형태]** 3중 인코딩. 색 라벨이 *1차 운반체*(색맹·오독 대응).
- **P2 숫자·그래프는 1차에 없다** — 첫 화면은 카드(이름·색·단계·화살표)만. %·그래프는 상세에서만(progressive disclosure).
- **P3 큰 글씨·낮은 밀도** — 한 화면의 1차 액션 ≤ 3개.
- **P4 색 = 단계, 매수/매도 신호 아님** — 모든 단계 표시 곁에 이 의미를 각인(§8 오독 방지).
- **P5 자극어 금지** — "위험·폭락·지금 사라"가 아니라 "끝물 가능성·추격 주의·관심이 빨라지는 중"(§8 카피 가이드).

## 1. 정보구조 (모바일 · 하단 탭)

```
┌─────────────────────────────────────────┐
│ 상단바: 야호 · "오늘 18:10 기준" · [범례/ⓘ]      │
├─────────────────────────────────────────┤
│ 콘텐츠 (활성 탭)                              │
│                                           │
│  [이야기 탭]                                 │
│   ┌ 오늘 한 줄 요약 (1차 · 상시) ───────────┐   │
│   │ "로봇이 새로 떠오르고, AI 반도체는 강세,    │   │
│   │  방산은 열기가 줄어드는 중입니다."          │   │
│   └─────────────────────────────────┘   │
│   단계 요약 칩:  ●막 시작 3   ◐한창 4   ▲조심 2    │
│   ── 막 시작 ──────────────────────────    │
│   [카드] [카드] [카드]                         │
│   ── 한창 ────────────────────────────    │
│   [카드] …                                  │
│   ── 조심 ────────────────────────────    │
│   [카드] …                                  │
│                                           │
│  [종목 탭]                                   │
│   검색창 [ 종목명·코드 입력            🔍 ]      │
│   → 종목 헤더 + 얽힌 이야기(테마)+단계 리스트       │
│                                           │
│ 면책 배너(상시·은은): "투자 정보 · 자문 아님"        │
├─────────────────────────────────────────┤
│ 하단 탭바:   이야기   │   종목     ( +P2 슬롯 )    │
└─────────────────────────────────────────┘
```
- **하단 탭 2개**: `이야기`(홈) · `종목`(역조회). Phase 2 확장(알림 등)은 탭바에 슬롯 예약(§11).
- 상단바: 앱명 · **갱신 시각 상시** · 우측 **범례/ⓘ**(색=단계 설명 재열람, 3차).
- 면책 배너는 모든 탭 하단에 **은은하게 상시**(§8).
- 상세는 카드 탭 시 **풀스크린 push**(§5).

## 2. `이야기` 탭 (홈) — 정보 요소

세로 스크롤 1화면에 통합 (지도와 3섹션은 같은 테마 집합의 두 뷰라 분리하지 않음).

1. **오늘 한 줄 요약** (1차·최상단 고정) — LLM 생성 평문 한 문장. 자극어 없음. 길면 말줄임 → 탭 시 펼침.
2. **단계 요약 칩** — `●막 시작 N` `◐한창 N` `▲조심 N`. 한눈에 시장 전체 분포. 칩 탭 = 해당 섹션으로 스크롤.
3. **3섹션 (세로)** — 각 섹션 헤더(색+형태+이름) 아래 해당 테마 카드:
   - **막 시작** — "관심이 빨라지는 중"인 이야기 후보(초반). 헤더 옆 작은 안내: *"지금 사라는 뜻이 아니에요"*(§8).
   - **한창** — 시장 중심 이야기(중간).
   - **조심** — 너무 올라 새 진입이 위험할 수 있는 이야기(끝물 가능성).
- 정렬: 섹션(막시작→한창→조심) 그룹 내 **관심 가속도순**. 카드 크기는 **균일**(크기 인코딩 미사용 — 초보 해석 부담 차단).

## 3. 테마 카드 — 해부 (Anatomy)

```
┌──────────────────────────────────────┐
│ ●    AI 반도체            초반 ▸     ↗   │
│ │    └ 테마명(大)    └ 단계 라벨   └ 화살표 │
│ └ 단계 인디케이터(색+형태)                  │
│  [신규 관측]  ← 신규 테마만                 │
└──────────────────────────────────────┘
```
- **요소**: ① 단계 인디케이터(색+형태) ② 테마명(큰 글씨) ③ **단계 꼬리표 텍스트**(`초반`/`중간`/`끝물 가능성`) ④ 화살표(`↑↗→↘↓` = 상승/하강/유지) ⑤ ('신규 관측' 배지 — 신규/무이력 테마, §7).
- **탭 동작**: 이야기 상세로 push(§5).
- **색 단독 금지(P1)**: 색이 안 보여도 ②④의 텍스트·형태만으로 단계를 읽을 수 있어야 함.

## 4. 신호등 색 ↔ 단계 — 시각 규칙 (의미만, 색상값은 범위 외)

| 단계 | 색(의미) | 형태 | 단계 라벨 | 의미 문구 |
|---|---|---|---|---|
| **초반** | 초록 | ● (채운 원) | `초반` | "관심 가져볼 만한 이야기" |
| **중간** | 노랑 | ◐ (반원) | `중간` | "이미 진행 중, 신중하게" |
| **끝물 가능성** | 빨강 | ▲ (삼각) | `끝물 가능성` | "끝물 가능성, 추격 주의" |
| **신규 관측** | 회색 | ○ (빈 원) | `신규 관측` | "아직 이력이 짧아 단계 판단 보류"(§7 cold-start) |

- **색은 보조, 단계 라벨이 1차 운반체.** [색+라벨+형태] 3중 인코딩 필수(P1).
- 정확한 색상값·대비·다크모드·채도는 **별도 비주얼 에이전트**가 본 IA(의미 매핑)를 입력으로 결정 — 본 문서 범위 외.

## 5. 이야기 상세 (카드 탭 → 풀스크린 push)

세로 순서(2차 밀도 — 숫자·그래프는 **이 화면에서만**):

1. **헤더** — 테마명 + 단계 인디케이터(색+라벨+형태) + 화살표.
2. **생애주기 위치 바** — `초반 ─●─ 중간 ─── 끝물` 위에 **현재 위치 점(스냅샷)**. ※ 단계는 되돌아가거나 건너뛸 수 있으며 반드시 초반→중간→끝물로 진행한다는 보장이 아니다(결정적 진행 트랙으로 그리지 않음 — 정직성). "이야기가 지금 어디쯤"을 한 눈에.
3. **2~3줄 설명** — LLM 생성, 이 이야기가 뭔지.
4. **(막 시작이면) 정직 문구 배너** — *"관심이 빨라지는 중입니다. '지금 사라'는 뜻이 아니며, 얼마나 앞서는지(리드타임)는 보장되지 않습니다."*(PRD §3).
5. **대표 종목 3 + 따라가는 종목 몇** — 종목명 칩. (판단성 코멘트 없음 — MVP, §8.)
6. **과거 비슷한 패턴 한 줄** — 정보성. 수익 보장·예측 표현 금지 + 면책(§8·PRD §9).
7. **숫자·그래프 영역** — 관심 추세 등(2차). 첫 화면엔 없던 정보가 여기서 처음 등장.
8. **하단 면책 배너**.
- 신규/무이력 테마면 4~7 대신 **'신규 관측' 안내**(데이터 부족 → 단계 보류, §7).

## 6. `종목` 탭 — 종목 → 테마 역조회 (읽기 전용)

- **진입/입력**: 탭 상단 검색창(종목명·코드). 자동완성·관심목록은 **Phase 2**(MVP는 단순 입력).
- **결과**:
  ```
  종목: 삼성전기
  이 종목이 얽힌 이야기
   ┌ AI 반도체     중간 ◐   ↗   ▸
   ├ 자동차/전장   초반 ●   →   ▸
   └ 로봇          끝물 가능성 ▲ ↘ ▸
  ```
  - 각 행 = 테마명 + 단계 인디케이터(색+라벨+형태) + 화살표, 탭 → 이야기 상세(§5).
- **판단성 코멘트 없음**(유지/비중 줄이기 등은 Phase 2 + 별도 법률 검토, PRD §9). MVP는 "이 종목 = 이 이야기들, 각 단계는 이렇다"는 **사실 표시만**.
- **빈 상태**: "이 종목은 현재 추적 중인 이야기에 속해 있지 않습니다."
- 하단 면책 배너.

## 8. 오독 방지 · 면책 · 카피 가이드  ★규제·신뢰의 핵심

### 8.1 '초록 = 사라' 오독 차단 (다층 방어)
1. **온보딩**에서 "색은 *단계*예요, 매수 신호가 아니에요" 명시(§9).
2. **상시 범례 한 줄** — 상단바 [범례/ⓘ] 또는 홈 상단에 "색 = 이야기의 단계(사라는 신호 아님)".
3. **카드 라벨 상시** — 색 옆에 `초반/중간/끝물` 텍스트 항상(색만으로 전달 금지, P1).
4. **단계 인디케이터 탭** → 범례 툴팁(초록=초반…).

### 8.2 면책 상시 표기
- 모든 탭·상세 하단에 **은은한 상시 배너**: *"투자 정보 제공 서비스이며 투자 자문·권유가 아닙니다. 투자 판단과 책임은 본인에게 있습니다."*
- (공유 기능은 Phase 2 — §11. 도입 시 공유 콘텐츠에도 면책 동반.)

### 8.3 카피 가이드 — 자극어 금지(PRD §9)
- **사람 작성 + LLM 생성 문구 모두 적용** — 오늘 한 줄 요약·이야기 2~3줄 설명 등 **LLM이 만드는 문구가 가장 눈에 띄는 1차 표면**이므로, 생성 지시에 카피 규칙 포함 + **자동 금지어 필터** + 배포 전 점검을 거친다.

| 쓰지 않는다 | 대신 쓴다 |
|---|---|
| 위험 / 폭락 / 떡상·떡락 | 끝물 가능성 / 식는 중 |
| 지금 사라 / 매수 추천 | 관심 가져볼 만 / 관심이 빨라지는 중 |
| 무조건·확실 / 급등 보장 | 가능성 / ~로 보입니다 |
| (개별 종목) 비중 줄여라 | (MVP 미사용 — 사실만 표시, Phase 2 법률 검토) |

## 9. 빈 / 최초 상태 — 첫날 길 잃지 않게

### 9.1 최초 실행 온보딩 (3카드 스와이프 · 큰 글씨 · 건너뛰기 가능)
1. **야호가 뭔지** — "어떤 이야기(테마)가 막 시작이고, 한창이고, 식는 중인지 보여주는 나침반이에요. *정답을 찍어주지 않아요.*"
2. **색 = 단계** — 신호등 범례(초록 초반·노랑 중간·빨강 끝물 가능성) + **"매수/매도 신호가 아니에요."**
3. **'막 시작'의 뜻 + 면책** — "관심이 빨라지는 중이라는 뜻이지 *지금 사라*는 뜻이 아니에요." + 면책 한 줄.
- 원칙: **1카드 1메시지**, 큰 글씨. '더보기'에서 재열람 가능.

### 9.2 빈 상태 (대화/데이터 없음 또는 첫 진입)
- 홈: 온보딩 직후 바로 오늘의 이야기 지도 노출(빈손 화면 금지). 데이터 미수집이면 "오늘 첫 집계를 준비 중이에요 — 보통 장 마감 후 갱신됩니다."
- 종목 탭: 검색 전 안내 "관심 종목을 입력하면, 그 종목이 어떤 이야기에 얽혀 있고 지금 어느 단계인지 보여드려요."

## 10. 데이터 → 화면 매핑 (PRD §5 파이프라인과 1:1)

```
판정 결과(테마 단계+색+화살표)        → 테마 카드 · 3섹션 분류 · 단계 요약 칩
이야기 LLM 요약(2~3줄)              → 이야기 상세 §5.3
"오늘 한 줄 요약"(LLM)              → 홈 최상단 §2.1
N:N 종목-테마 역인덱스               → 종목 탭 역조회 §6
관심 추세·기간 수익(숫자·그래프)       → 이야기 상세 §5.7 (2차에서만)
cold-start('신규 관측')             → 회색 ○ 배지 + 보류 안내 §7
일1회 스냅샷 시각 / 추가 갱신          → 상단바 갱신 시각 · '오늘 추가로 갱신됨' 표시 §7
과거 패턴(정보성)                    → 이야기 상세 §5.6 (수익 보장 표현 금지)
```
- 화면은 **읽기 API의 일1회 스냅샷**만 소비(실시간 없음). 갱신 시각을 상시 노출해 신선도를 사용자가 인지.

## 12. 결정 로그

1. **내비게이션** → 하단 탭 2개(`이야기`/`종목`) + 상세 push. 두 진입 의도 분리, 탭바 확장 여지.
2. **홈·3섹션 배치** → 한 탭 세로 스크롤 통합(요약→단계칩→3섹션). 분리는 흐름 끊음.
3. **이야기 지도 레이아웃** → 균일 카드 리스트(단계 그룹) + 단계 요약 칩, 크기 인코딩 미사용.
4. **테마 카드 해부** → 단계 인디케이터+테마명+단계 라벨+화살표, 탭→상세.
5. **색-단계 시각 규칙** → 색 단독 금지, [색+라벨+형태] 3중, 라벨이 1차. 색상값은 비주얼 에이전트.
6. **progressive disclosure** → 카드 탭→풀스크린 push 상세, 숫자·그래프는 상세에서만.
7. **오늘 한 줄 요약** → 홈 최상단 고정 1줄(LLM)+갱신시각. **LLM 생성물에 카피 규칙·금지어 필터 강제(§8.3). `[v1.1]`**
8. **3섹션 표현** → 세로 섹션 헤더+카드. '전체 흐름 한눈'.
9. **이야기 상세** → 헤더→생애주기(현재 스냅샷)→설명→(막시작 배너)→종목→과거 한 줄→그래프→면책. **생애주기는 결정적 진행 트랙 아님. `[v1.1]`**
10. **막 시작 정직 문구** → 상세·섹션에 "관심 빨라지는 중·리드타임 미보장" 배너.
11. **종목 역조회** → `종목` 탭 검색→얽힌 이야기+단계 사실 표시, 코멘트 없음(MVP).
12. **상태 처리** → 로딩 스켈레톤/에러 재시도/빈 안내/'신규 관측' 배지/갱신시각. **'추가 갱신'은 '오늘 추가로 갱신됨' 중립 표현, 트리거는 PRD와 함께 정의. `[v1.1]`**
13. **오독 방지** → 온보딩+상시 범례+라벨 상시+툴팁 다층.
14. **면책·카피 가이드** → 전 화면 상시 면책 + 금지어/허용어 표.
15. **온보딩** → 3카드 스와이프(나침반·색=단계·막시작 뜻+면책), 재열람 가능.
16. **타이포/접근성** → 큰 글씨·낮은 밀도·색+라벨+형태·숫자 최소(IA 차원). 타이포 시스템은 비주얼 에이전트.
17. **전이·뒤로** → push/back 표준. **공유(딥링크/URL)는 MVP 제외 → Phase 2**(FR 정식화 + 규제 검토). `[v1.1]`
18. **Phase 2 슬롯** → 탭바 알림 슬롯·종목 탭 심화·상세 돈흐름 섹션 예약(MVP 비노출).
19. **데이터→화면 매핑** → 판정/요약/역인덱스/스냅샷을 화면 요소에 1:1(§10).
20. **문서 범위** → IA(정보·색 의미)만. 색상값·타이포·간격은 별도 비주얼 에이전트.

> **v1.1 변경(grill-review Advisory 4 반영)**: D7(LLM 카피 가드레일·§8.3) · D9(생애주기 '현재 스냅샷') · D12('추가 갱신' 중립 표현) · D17(공유 → Phase 2). 모두 화면 내용 수준 수정.
