## 문서화 기준 결정 로그

이 문서는 `/grill-yourself` 방식으로 질문 없이 기준을 확정해서 작성했다.

1. **"모든 기능"의 범위** -> **사용자에게 보이는 화면 기능, 상호작용, 코드상 동작 함수, 데이터 기반 자동 렌더링 기능을 모두 포함한다.** 단순 데이터 필드만 있고 UI/계산에 쓰이지 않는 값은 해당 섹션의 데이터 근거로 묶는다.
2. **라이브 사이트와 로컬 저장본 중 우선순위** -> **로컬 저장본을 1차 근거, 라이브 브라우저 실행 결과를 검증 근거로 사용한다.** 사용자가 로컬 자료도 참고하라고 했고, 저장본에는 렌더링 완료 상태가 포함되어 있다.
3. **기능 분류 단위** -> **탭/페이지 단위로 먼저 정리하고, 공통 기능과 내부 알고리즘을 별도 정리한다.** 실제 사용자가 기능을 찾는 방식과 가장 가깝다.
4. **미노출 코드 처리** -> **현재 HTML에서 연결 요소가 없지만 JS에 남아 있는 기능은 "코드상 잠재 기능"으로 분리한다.** 실제 제공 기능과 혼동을 줄이기 위해서다.
5. **투자 문구 처리** -> **기능 설명은 있는 그대로 쓰되, 투자 자문 여부와 데이터 신뢰 충돌은 리스크로 별도 표기한다.** 사이트가 교육/시뮬레이션 문구와 실제 데이터/매매 지시형 문구를 동시에 사용하기 때문이다.

## 공통 기능

### 상단 헤더

- 앱명과 버전 표시: `지혜로운 투자 앱 · 한국 100`, `Korea 100 Edition v3.0`.
- AI Pipeline 상태 칩 표시: 기본값은 `AI Pipeline Idle`.
- 전역 `시뮬레이션 실행` 버튼 제공.
- 전역 `초기화` 버튼 제공.
- 헤더는 sticky로 고정되어 스크롤 중에도 유지된다.

### 탭 네비게이션

- 9개 탭을 `data-page` 기반으로 전환한다.
- 탭 클릭 시 해당 `.page-content`만 보이고 나머지는 숨긴다.
- 탭 전환 시 상단으로 부드럽게 스크롤한다.
- 백테스트 탭 진입 시 `renderBacktest()`가 지연 실행된다.
- 회장님 보고 탭 진입 시 `renderReport()`가 지연 실행된다.
- 모바일에서는 탭 바가 가로 스크롤된다.

### 데이터 배너

- 한국 100개 종목 실제 시세/뉴스 데이터 연동 배너를 모든 페이지 상단에 노출한다.
- 마지막 시세 갱신 시각을 표시한다.
- `last_update.json?_=timestamp`를 fetch해서 갱신 시각을 보정한다.
- 표시 항목:
  - 종목 수
  - KOSPI/KOSDAQ 구성
  - 섹터 수
  - 평가 기준
  - 데이터 출처 문구

### 캐시 무력화

- HTML head에서 `Cache-Control`, `Pragma`, `Expires`를 설정한다.
- `localStorage.__forest_fetch_ts`를 사용해 forest 데이터 갱신 시점을 추적한다.
- 5분 이상 지난 세션이면 `cb=` 쿼리스트링을 붙여 강제 새로고침한다.
- 외부 데이터 JS에 버전 쿼리스트링을 붙인다.

### 공통 차트

- Chart.js 사용.
- 시뮬레이션 탭에서 레이더 차트와 도넛 차트를 사용한다.
- 백테스트 탭에서는 자체 canvas 라인 차트를 사용한다.

## 3. 100종목 시뮬레이션 탭

목적: 한국 100종목을 사용자가 지정한 투자 철학과 시장 조건으로 점수화하고, 최종 포트폴리오와 집행 계획을 만든다.

### 아키텍처 개요

- 3단계 파이프라인 설명:
  - Stage 1: Information
  - Stage 2: Judgment
  - Stage 3: Action
- 한국 KOSPI/KOSDAQ 100개 종목 대상.
- 3축 기본 점수:
  - 독점성
  - 대세
  - 본질
- 보너스 배지:
  - 미국 노출
  - 게임체인저
  - 10년 성장
  - 외인 매수
  - 조정장 구간 보너스

### 투자 철학 가중치 설정

슬라이더:
- 독점성 Moat
- 대세 추종 Momentum
- 기업 본질 Fundamentals

동작:
- 세 슬라이더 값을 100%로 정규화한다.
- 가중치 비중에 따라 철학 태그를 갱신한다.
- 철학 태그:
  - Moat-Heavy
  - Momentum-Heavy
  - Value-Heavy
  - Balanced

### 프리셋

버튼:
- 단기형
- 버핏형
- 성장형
- 추세추종
- 균형

프리셋 가중치:
- 단기형: 독점성 30, 대세 50, 본질 20
- 버핏형: 독점성 45, 대세 15, 본질 40
- 성장형: 독점성 30, 대세 40, 본질 30
- 추세추종: 독점성 15, 대세 60, 본질 25
- 균형: 독점성 35, 대세 30, 본질 35

### 실전 조건 설정

- 통과 임계값: 40~90점
- 최대 포지션: 종목당 5~30%
- 보유 호흡:
  - 단기 1~3개월
  - 중기 6~12개월
  - 장기 3~5년
- 시장 국면:
  - 강세장
  - 조정/횡보
  - 약세장
- 현금 유보: 0~60%
- 종목 수: Top 3~15

### Stage 1 - 정보 수집

- 100개 종목의 가격/재무/뉴스 수집 시뮬레이션.
- 진행 카운터: `0/100`에서 `100/100`.
- 로그 박스에 수집 완료 메시지 표시.
- 실제 브라우저 점검 기준 약 9초 내 100개 수집 완료.

### Stage 2 - 판단

- 각 종목별 점수를 계산한다.
- 통과 임계값 이상이면 통과, 미만이면 탈락.
- 유니버스 필터가 있으면 필터 외 종목은 제외 처리한다.
- 통과/탈락 결과를 테이블에 실시간 반영한다.
- 통과 종목 평균 독점성/대세/본질을 레이더 차트에 표시한다.
- 실제 브라우저 점검 기준 전체 100종목 실행 시 66개 통과.

### Stage 3 - 행동

- 통과 종목을 점수순으로 정렬한다.
- 설정된 Top N만 최종 선택한다.
- 현금 유보를 제외한 투자 비중을 점수 비례로 배분한다.
- 종목당 최대 포지션 제약을 적용한다.
- 배분 합계를 다시 정규화한다.

## 코드상 잠재 기능 또는 불완전 연결

### Wise Investor 별도 실행

`app.js`에 다음 함수가 존재한다.

- `computeWiseScore()`
- `selectWisePicks()`
- `buildWiseRationale()`
- `runWiseInvestor()`
- `renderWiseResult()`

기능 추정:
- 별도 Wise Score로 Top 5를 선택.
- 5개 종목에 25/22/20/18/15 비중을 부여.
- 현금 비중 계산.
- 점수 분해와 매수 논리를 카드로 표시.

현재 저장본 HTML에서 `wiseGoBtn`, `wiseResult`가 확인되지 않아 사용자에게 노출되지 않는 잠재 기능으로 분류한다.

### `buy` 탭 링크

황 4상자 결과 설명 안에 `showPage('buy')`가 있으나 현재 탭 목록에는 `buy` 페이지가 없다. 클릭 시 실제 페이지가 없어서 화면이 빈 상태가 될 가능성이 있다.

### 라이브 사이트의 forest 강제 표시

라이브 HTML에는 로드 직후 일정 시간 `forest` 탭을 강제 표시하는 스크립트가 있었다. 로딩 직후 다른 탭을 빠르게 누르면 다시 시대 진단서로 돌아갈 수 있다.

### 데이터/자문 문구 충돌

사이트는 상단에서 `실제 시세·뉴스 데이터 연동`, `Realtime Finance`라고 표시하지만 footer에서는 `데이터는 예시`라고 표시한다. 또한 `사지 마세요`, `무조건 파십시오`, `매수가/손절가/익절가` 같은 문구는 교육용 시뮬레이션을 넘어 투자 자문처럼 읽힐 수 있다.
